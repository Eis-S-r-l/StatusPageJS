# Bundled fonts

Inter (variable weight 100–900) and Manrope (variable weight 200–800), Latin WOFF2 subsets covering the English and Italian UI. Served locally by `next/font/local`; builds and visitors need no connection to Google Fonts.

Downloaded from Google Fonts on 2026-09-10:

- Inter: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Manrope: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2

The accompanying SIL Open Font Licenses are from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/manrope
